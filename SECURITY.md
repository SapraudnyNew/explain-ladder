# Security

This repository is shared as is and is not actively maintained, but security reports are read.

To report a vulnerability, open the **Security** tab of this repository and choose
**Report a vulnerability**. That creates a private report that only the maintainer sees. Do not
open a public issue or pull request for it.

Vendored skills under `plugins/explain-ladder/skills/` come from other projects, named in each
folder's `UPSTREAM` file. A problem in their code is best reported to that upstream project too.

This repository holds no keys or credentials. If you find one, report it the same way.
